# V1.0 / V1.0.2 暂不开放的功能

个人主体小程序 V1.0 不提供照片墙；V1.0.2 进一步下线投票。两项功能都在客户端版本中直接下线，没有远程开关。Java 后端、数据库结构、历史记录和 MinIO 文件均保留。

## 照片墙

已从 `app.json` 移除 `pages/photo-wall/index`、`pages/photo-detail/index`，并从活动详情移除照片 Tab、上传和浏览入口。照片页面、`services/photo.js`、`utils/photo-ui.js` 保留在仓库，但被 `packOptions.ignore` 排除。V1.1 恢复前需完成真实微信内容安全审核，然后恢复页面注册、活动详情入口和对应打包项，验证上传、审核、浏览与点赞。详见 [V1.0 照片墙下线记录](v1.0-photo-wall-disabled.md)。

## 投票

已从 `app.json` 移除 `pages/poll-list/index`、`pages/poll-create/index`、`pages/poll-detail/index`。三个页面目录、`services/poll.js`、`utils/p1-display.js` 保留在仓库，但被 `packOptions.ignore` 排除。活动详情和行程详情不展示投票；行程编辑仅直接保存行程；活动列表、活动详情与我的待办会过滤历史投票待办，并按可见待办重新计数。通用请求保留在 `services/collaboration.js`。

切换到符合微信投票服务类目要求的非个人主体并发布新版本时，需：

1. 在 `app.json` 重新注册三个投票页面，并从 `packOptions.ignore` 移除三个目录、`services/poll.js`、`utils/p1-display.js`。
2. 恢复活动详情的投票 Tab、列表与跳转，调整 Tab 列数；恢复行程详情的关联投票与入口，以及行程编辑的联合创建路径。
3. 恢复投票待办展示与跳转，同时重新核对活动列表和详情中的待办计数；`services/poll.js` 中的投票 API 继续供投票页面使用。
4. 复测历史投票、创建、参与、结果应用、待办、行程联动与包体积，再提交审核。
