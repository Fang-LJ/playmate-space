# V1.0 照片墙下线记录

V1.0 不提供活动照片墙、活动照片上传、照片点赞或照片详情。活动封面、用户头像和账单凭证上传仍按原有功能运行，它们不是照片墙。

## 前端下线范围

- `app.json` 不再注册 `pages/photo-wall/index` 和 `pages/photo-detail/index`。
- 活动详情页移除了“照片” Tab、最近照片、上传入口、照片状态、照片墙跳转，以及对应的请求、页面状态和样式。
- 活动列表和登录页的宣传文案不再承诺活动照片功能。
- `project.config.json` 的 `packOptions.ignore` 排除照片墙页面、`services/photo.js` 与 `utils/photo-ui.js`，避免这些保留的源码进入 V1.0 上传包。

## 保留的源码与数据

`pages/photo-wall/**`、`pages/photo-detail/**`、`services/photo.js`、`utils/photo-ui.js` 和通用文件服务中的照片辅助方法仍保留在仓库中。后端照片 API、数据库结构、已有照片数据及 MinIO 文件未改动。

## V1.1 恢复

完成真实的微信内容安全审核并通过新版本发布前，需要：

1. 从 V1.0 前的版本恢复活动详情页的照片 Tab、请求、状态、跳转和样式，并在 `app.json` 重新注册两个照片页面。
2. 从 `packOptions.ignore` 移除两个照片页面目录、`services/photo.js` 和 `utils/photo-ui.js` 对应项。
3. 复测照片上传、审核状态、列表、详情、点赞与分享等完整流程，并重新检查主包体积；如有必要，再将照片墙放入分包。

V1.0 采用明确的客户端版本下线，没有远程开关。
